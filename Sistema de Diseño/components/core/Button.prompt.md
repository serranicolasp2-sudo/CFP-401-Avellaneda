Pill-shaped institutional button — use `primary` (azul) for the main action on a page and `accent` (amarillo) for enrolment CTAs like "Inscribite".

```jsx
<Button variant="accent" size="lg" href="#inscripcion">Inscribite ahora</Button>
```

Variants: primary, accent, secondary (outline azul), ghost. Sizes sm/md/lg. Never use more than one accent button per view — the yellow is the loudest thing in the palette.
