Official marks only. `assetBase` is the relative path from the rendering HTML file to `assets/`.

```jsx
<Logo variant="campus" height={44} assetBase="../../assets" />
```

Variants: `institucional` (horizontal lockup, blue) · `institucional-blanco` (same, white text + yellow squares, for navy grounds) · `vertical` / `vertical-blanco` (stacked lockup with "Desde 1979") · `sello` (stacked "C.F.P. N°401 Avellaneda") · `arco` / `arco-blanco` (arch mark alone, for watermarks) · `campus` — **Campus Virtual only, never on institutional surfaces** · `fundacion-uocra` (partner mark).
